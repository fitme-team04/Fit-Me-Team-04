# DB 예시 코드

PyMySQL 로 예시 DB 를 읽고 쓰는 파이썬 예시 180개: 그룹 6개 × 난이도 3단계 × 10개.

- 그룹: `공통/브랜드` · `공통/사람` · `공통/옷` (모든 파트 공통) / `3d` · `ai` · `front` (파트별)
- 단계 폴더: `1_기본` → `2_심화` → `3_고급`, 그 안에 `01_….py` ~ `10_….py` (SQL 이 쉬운 순)
- 파일 이름이 목적이고, 첫 줄 `# 목적:`·`# 누가 쓰나:`·`# 난이도:`·`# 실행:` 과 함수마다 `# 목적:` 주석이 있음

난이도 기준
- 기본: 표 1개, WHERE·ORDER BY·LIMIT
- 심화: 표 2~3개 JOIN·LEFT JOIN, GROUP BY·HAVING
- 고급: 표 4개 이상·계산식·피벗·파생 테이블·창 함수·트랜잭션 쓰기(되돌림)·파이썬 알고리즘

도우미(예시가 아님, 이 폴더 바로 아래): `_db.py` 접속·조회·표 출력·쓰기·`--save`(루트 `out/`) / `_body_type.py` BMI → 체형 / `_검증.py` 입력 검사 / `_추정.py` k-NN 치수 추정 / `_추천.py` 규칙 사이즈 추천 / `_학습표.py` 학습 표

실행 (저장소 루트에서, 자세히는 루트 `실행_가이드.txt` 3번)
- `bash db/예시_코드/예시_실행.sh` — 폴더 목록·파일 수
- `bash db/예시_코드/예시_실행.sh 공통/브랜드/1_기본` — 단계 하나 (01 → 10)
- `bash db/예시_코드/예시_실행.sh ai` — 그룹 하나 (기본 → 심화 → 고급)
- `bash db/예시_코드/예시_실행.sh all --quiet` — 전부, 파일별 성공·실패만 → `성공 180 / 실패 0`
- 파이썬은 `PYTHON` → 루트 `.venv/bin/python` → `python3` 순. 전제: MySQL 컨테이너 실행 + 예시 데이터 적재(`setup.sh`), Docker 와 같은 OS 안에서 실행

# recommend — 사이즈 추천

## 들어 있는 것
| 파일 | 하는 일 | 언제 쓰나 (예) |
|---|---|---|
| `01_size_fit.sql` | 사이즈 × 항목별 여유분 (`ease_cm` = 옷 × factor − 몸) | 어느 항목이 끼는지 자세히 볼 때 |
| `02_size_rank.sql` | 사이즈별 최소·평균 여유분, `size_status`(fit/small), 추천 순서 정렬 | "이 상품은 M 추천" 한 줄 결과가 필요할 때 |
| `03_body_range_fit.sql` | 브랜드 권장 체형 범위(low~high) 안에 드는 항목 수 | 브랜드가 신체 기준 사이즈표만 줄 때 |

## 사용법
1. `@user_id`, `@garment_id` 를 바꿔 실행 (사용자의 최근 `profiles` 행 기준).
2. 02 의 첫 행이 추천 사이즈: 모든 항목 여유분 ≥ 0 인 사이즈 중 평균 여유분이 가장 작은 것.

## 주의
- 대응 규칙은 `ref.measure_maps` (가슴둘레 ↔ 가슴단면 × 2.00 등 8개). 규칙이 없는 항목은 비교되지 않는다.
- PoC 단순 규칙이다. 핏(slim/oversized)별 여유분 기준은 아직 없다.

# 입어봄 V2 디자인 참고 작품

중고 거래에서는 한 매물에 살 수 있는 옷이 한 벌뿐이다. 판매자는 그 옷을 어떻게 쟀는지 보여 주고, 구매자는 거래 전에 자기에게 맞을지 가늠할 수 있어야 한다. 다섯 작품에서 이 두 사람이 다음 행동을 결정하는 데 필요한 요소를 골랐다.

| 화면 | 원작에서 참고한 요소 | 입어봄에 적용한 방식 |
| --- | --- | --- |
| 홈 | 크림 지면을 대각선으로 잘라 사진을 드러내고, 왼쪽의 큰 제목과 사각 버튼 옆에 원형 화살표를 둔다. [Echo & Thread · Bea Grey](https://dribbble.com/shots/26884567-Echo-Thread-Modern-Fashion-Landing-Page-Hero) | 홈 화보에 같은 사선 프레임을 적용했다. 사진 왼쪽에 Instrument Serif 정체·이탤릭 두 줄 제목을 겹치고, 사각 버튼과 원형 화살표를 각각 판매와 구매 진입에 썼다. |
| 착용샷 | 착장 사진에 표시된 지점을 누르면 해당 상품을 탐색한다. [Editorial Style Fashion Homepage · Spiralclicks](https://dribbble.com/shots/26973507-Editorial-Style-Fashion-Homepage) | 티셔츠 위의 가슴·어깨·총장 표시를 누르면 그 위치의 측정선과 아래 치수가 함께 선택된다. 사진 아래의 치수 버튼으로도 같은 위치를 찾을 수 있다. |
| 판매자 등록 | 사진 업로드부터 정보 작성과 게시까지 판매 단계를 드러낸다. [Shao · ME UI/UX Designer](https://dribbble.com/shots/25863721-Shao-Sell-Your-Needless-Product) | ‘옷 준비 → 치수 확인 → 매물 공유’에서 현재 위치를 표시한다. 판매자는 자기가 고른 사진을 보며 치수와 출처를 확인한 뒤 매물을 공유한다. |
| 구매자 실측표 | 사이즈 가이드에 측정 방법과 핏 설명을 별도로 마련했다. [Everlane · Jack Sinclair](https://dribbble.com/shots/16179106-Our-New-Size-Guide-Experience) | 매물 실측 아래에서 ‘내 옷에서 같은 부위 재는 법’을 펼친다. 상의 총장은 어깨, 하의 총장은 허리부터 재도록 해당 매물에 맞는 설명을 보여 준다. |
| 구매자 핏 결과 | 한 상품 화면의 동일한 조작 영역이 선택한 기능에 맞춰 바뀐다. [THORNWORK 콘셉트 · Sayeed Ahmad](https://dribbble.com/shots/27764674-Ecommerce-Product-Page-Mobile-UI-and-Motion) | 키·몸무게로 판단하기 어려울 때 결과 자리에서 내 옷 단면 비교를 연다. 판매 옷과 내 옷의 값을 나란히 보고 키·몸무게 기준으로 돌아갈 수 있다. |

홈의 인물 화보와 구매자 입구의 의류 행거 사진은 입어봄용으로 새로 제작했다. 화면의 한글 인터페이스는 Pretendard를 사용한다. 두 서체와 배포 라이선스는 앱에 포함되어 있다.

‘3D 실측 스튜디오’의 브릭 티셔츠는 시연용이다. 54·47·68cm는 예시 매물에 저장하는 값이며, 착용샷의 선은 어디를 재는지 보여 준다. 3D 윤곽은 정면 사진에서 만든 형태로 옆면의 두께를 추정한다. 실제 매물에서는 판매자가 등록한 값과 측정 출처를 사용한다.

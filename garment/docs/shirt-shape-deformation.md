# 기준점 기반 의류 출력 정책

상의 v18.2는 기존 메시의 정점과 연결 구조를 유지하면서 네 치수를 조절하고 어깨·소매끝 기준점을 함께 내보냅니다. 하의는 기존 일곱 치수 케이지 변형과 기준점 출력을 유지합니다.

신체 교차에 따른 밀어내기 보정과 출력 차단을 제거했습니다. 자체 교차 후보에 따른 차단도 제거했습니다. 신체를 뚫고 지나가더라도 계산된 의류를 그대로 출력합니다. 입력 범위, 바인딩 무결성, 비정상 숫자·면 붕괴·뒤집힘 검사는 유지합니다.

현재 상의는 어깨 기준 소매와 기본 설정의 90~110%를 지원하며 뒷목 기준은 별도 환산이 필요합니다. 그림을 이용해 추가했던 F→G 추정 환산은 사용자 요청으로 취소했습니다. 기본 형상과 허리·소매 비율을 유지하는 변형은 계속 사용합니다. `shirt_shape.py`에서 교차 보정 함수를 삭제했고 `template_binding.py`에서 기준 신체 데이터 요구와 교차 검사 호출을 제거했습니다.

21개 조합이 모두 생성됐으며 기준점 기반 계산 결과에 추가 신체 보정이 없음을 확인했습니다. 기준 신체 교차가 없는 것은 5개이고 나머지 16개도 차단하지 않습니다. 이전에 거절되던 네 치수 동시 -5%를 실제 worker에서 GLB로 내보내 재입력·렌더링했습니다. 검사 결과의 교차 수는 진단 정보입니다.

원본 목둘레 자체 겹침 후보 3쌍은 유지됩니다. 무교차·무손상 모델을 보장하는 정책은 아닙니다. 치수 입력과 측정 메타데이터는 케이지 기준이며 완성 메시의 실제 실측을 보증하지 않습니다.

통합 폴더의 갱신 코드와 `models/registry.json`을 VM에 함께 배포합니다. `GARMENT_TEMPLATE_DIR`은 최종 모델 폴더를 가리켜야 합니다. VM 반영과 Blob 업로드는 아직 수행하지 않았습니다.
